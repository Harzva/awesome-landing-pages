github.io 不等于开源

页面能浏览、仓库可见、作品可复用，是三件不同的事。

Pages 是托管地址

GitHub Pages 发布静态网站。看到 github.io，只能说明页面托管在 GitHub Pages。

仓库访问另行判断

在账号计划和仓库设置允许时，私有仓库也可以发布 Pages。页面公开不代表访客能看仓库；浏览器可见的 HTML/JS 也可能只是构建产物，不等于原始工程或后台源码。

复用要看许可证

即使代码公开，也应先查看仓库许可证及页面素材的权利说明；未注明许可，不等于允许复制。
